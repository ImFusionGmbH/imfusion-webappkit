# External references

This directory contains external ImFusion SDK documentation and source code used
as development context. It is not part of WebAppKit, its user documentation, or
its release artifacts.

May include contents like:

- `python-sdk/` — generated ImFusion Python SDK documentation;
- `web-sdk/` — ImFusion Web SDK source; and
- `web-viewer/` — ImFusion web viewer source.

These resources must be obtained separately and may require ImFusion access or
licenses. Local copies can be excluded from version control.
